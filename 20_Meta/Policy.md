# P-Reinforce 분류 정책 (RL Policy)

> **버전:** 1.0.0 | **최초 생성:** 2026-05-08 | **정책 엔진:** P-Reinforce v1.0

---

## 📊 현재 보상 가중치 (Reward Weights)

| 가중치 | 항목 | 현재값 | 설명 |
|--------|------|--------|------|
| `w₁` | Categorization Accuracy | **0.45** | 문서가 올바른 카테고리에 배치된 정도 |
| `w₂` | Graph Connectivity | **0.35** | 신규 문서가 기존 지식 그래프와 연결된 밀도 |
| `w₃` | User Satisfaction | **0.20** | 사용자 피드백(칭찬/수정/방치) 기반 만족도 |

**보상 함수:**
```
R = 0.45 × Categorization_Accuracy
  + 0.35 × Graph_Connectivity
  + 0.20 × User_Satisfaction
```

## 📁 카테고리 분류 기준 (Classification Rules)

### 10_Wiki/🛠️ Projects
- **기준:** 명확한 목표/결과물이 있는 진행 중 또는 완료된 작업
- **유사도 임계값:** 0.88
- **키워드 신호:** 프로젝트명, 브랜드, 산출물, 납기, 스펙

### 10_Wiki/💡 Topics
- **기준:** 특정 프로젝트에 종속되지 않는 재사용 가능한 개념/방법론
- **유사도 임계값:** 0.85
- **키워드 신호:** 원리, 기법, 이론, 방법론, 비교, 역사

### 10_Wiki/⚖️ Decisions
- **기준:** '왜 이 방법을 선택했는가'에 대한 의사결정 기록
- **유사도 임계값:** 0.90
- **키워드 신호:** 선택, 결정, 근거, 트레이드오프, 대안 검토

### 10_Wiki/🚀 Skills
- **기준:** 반복 실행 가능한 나만의 워크플로우, 프롬프트, 패턴
- **유사도 임계값:** 0.87
- **키워드 신호:** 에이전트, 자동화, 워크플로우, 시스템 지침, 스크립트

## 🔄 피드백 학습 규칙 (Feedback Learning Rules)

| 사용자 행동 | 에이전트 반응 |
|------------|--------------|
| "이 분류 완벽해" (칭찬) | 해당 카테고리의 `w₁` 가중치 +0.02 |
| "이건 A가 아니라 B 폴더로" (수정) | A↔B 경계 재설정, 양쪽 유사도 임계값 재보정 |
| 수정 없이 계속 사용 (방치=암묵적 보상) | 현재 구조 고착, `policy_version` 마이너 버전 업 |
| 파일 삭제 (거부) | 해당 카테고리 분류 신뢰도 -0.05 |

---

## 🚨 구조 재설계 트리거 (Refactoring Triggers)

- 단일 폴더 파일 수 **> 12개** → 하위 카테고리 세분화 제안
- `confidence_score < 0.70` 문서 누적 **> 3개** → 분류 정책 긴급 재검토
- `Graph.json` 연결 없는 고립 노드 **> 5개** → 강제 링크 생성 또는 `00_Raw`로 격하
