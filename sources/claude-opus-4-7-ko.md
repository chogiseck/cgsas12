# Claude Opus 4.7 소개

> 원문: https://www.anthropic.com/news/claude-opus-4-7
> 번역일: 2026-04-23

---

Claude Opus 4.7이 오늘 정식 출시되었습니다.

Opus 4.7은 고급 소프트웨어 엔지니어링 분야에서 Opus 4.6을 크게 뛰어넘는 성능 향상을 이루었으며, 특히 가장 어려운 작업에서 두드러진 발전을 보입니다. 사용자들은 이전에는 꼼꼼히 감독해야 했던 까다로운 코딩 작업을 이제 Opus 4.7에게 안심하고 맡길 수 있다고 말합니다.

Opus 4.7은 복잡하고 오래 걸리는 작업을 꼼꼼하고 일관되게 처리하며, 지시 사항을 정확하게 따르고, 결과를 보고하기 전에 스스로 검증하는 방법을 찾아냅니다. 이 모델은 시각 능력도 크게 향상되어 더 높은 해상도의 이미지를 볼 수 있습니다. 또한 전문적인 작업을 수행할 때 더욱 세련되고 창의적인 결과물을 만들어내며, 더 높은 품질의 인터페이스, 슬라이드, 문서를 제작합니다.

---

## 에이전트 기능 향상

### 더 깊은 사고력

Opus 4.7은 특히 에이전트 환경의 후반 턴(대화 후반부)에서 더 높은 노력 수준으로 더 깊이 생각합니다. 이를 통해 어려운 문제에서 신뢰성이 향상되지만, 더 많은 출력 토큰이 생성됩니다.

Anthropic은 새로운 **xhigh(초고)** 노력 수준을 도입했습니다. 이는 기존의 high(높음)와 max(최대) 사이에 위치하며, 개발자들이 사고의 깊이와 응답 속도 사이의 균형을 더 세밀하게 조정할 수 있게 해줍니다.

**권장 사항:**
- 코딩 및 에이전트 작업에는 새로운 xhigh 노력 수준을 사용하세요.
- 지능이 중요한 대부분의 작업에는 최소 high 노력 수준을 사용하세요.

### 작업 예산 (Task Budgets)

Opus 4.7은 작업 예산을 도입합니다. 이 기능은 Claude에게 전체 에이전트 루프(생각, 도구 호출, 도구 결과, 최종 출력 포함)에서 목표로 삼아야 할 토큰 수를 대략적으로 알려줍니다. 모델은 실시간으로 카운트다운을 보면서 예산이 소진됨에 따라 작업의 우선순위를 정하고 작업을 우아하게 마무리합니다.

작업 예산은 공개 베타로 출시되며, 개발자들이 더 긴 실행 과정에서 Claude의 토큰 사용을 안내하고 작업 우선순위를 정할 수 있는 방법을 제공합니다.

## 사이버 보안 안전장치

Anthropic은 Opus 4.7을 금지되거나 위험도가 높은 사이버 보안 사용을 자동으로 감지하고 차단하는 안전장치와 함께 출시합니다.

Opus 4.7은 Anthropic이 Mythos급 모델의 광범위한 출시로 나아가기 전에 덜 강력한 모델에서 새로운 사이버 안전장치를 먼저 테스트하는 첫 번째 모델입니다. Opus 4.7의 사이버 능력은 Mythos Preview만큼 고급스럽지는 않으며, 금지되거나 위험도가 높은 사이버 보안 사용을 나타내는 요청을 자동으로 감지하고 차단하는 안전장치가 탑재되어 있습니다.

취약점 연구, 침투 테스트, 레드팀 활동 등 합법적인 사이버 보안 목적으로 Opus 4.7을 사용하고자 하는 보안 전문가는 새로운 **사이버 검증 프로그램(Cyber Verification Program)**에 참여할 수 있습니다. 이 프로그램을 통해 Anthropic은 사이버 보안 전문가들의 계정에 대한 제한을 완화하여 더 광범위한 요청을 허용할 예정입니다.

## 고해상도 시각 능력

Claude Opus 4.7은 고해상도 이미지 지원을 갖춘 최초의 Claude 모델입니다.

- **최대 이미지 해상도**: 2,576px / 3.75MP
  (이전 한도 1,568px / 1.15MP에서 **3배 이상** 향상)

이를 통해 시각 집약적인 작업에서 성능이 크게 향상되며, 특히 컴퓨터 사용, 스크린샷 분석, 아티팩트 이해, 문서 처리 워크플로우에서 중요한 개선이 이루어집니다.

초기 접근 파트너 중 한 곳이 자율 침투 테스트를 위한 컴퓨터 비전 분야에서 테스트한 결과, 시각 정확도가 Opus 4.6의 54.5%에서 **98.5%**로 급등했습니다.

| 벤치마크 | Opus 4.6 | Opus 4.7 | 개선 |

- MCP-Atlas 77.3%는 멀티툴 조율 워크플로우에서 업계 최고 수준입니다.

## 마이그레이션 가이드

Opus 4.7은 Opus 4.6을 대체하는 드롭인 업그레이드(별도 코드 변경 없이 교체 가능)입니다.

**새로운 기능을 활용하려면:**

1. **xhigh 노력 수준 사용**: 코딩 및 에이전트 작업에서 더 깊은 추론이 필요할 때
2. **작업 예산 설정**: 긴 에이전트 실행에서 토큰 사용을 제어하고 싶을 때
3. **고해상도 이미지 활용**: 시각적 분석 작업에서 2576px까지 이미지를 전달할 때
